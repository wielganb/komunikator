# B&E Messenger — v0.4 UI Demo

Demo klienta Android przygotowany pod GitHub → Codemagic → APK.

## W tej wersji
- poprawione marginesy i obsługa pasków systemowych Androida,
- czytelny tekst wpisywany przez użytkownika,
- większe dymki wiadomości z kontrolowaną szerokością,
- zawijanie długich wiadomości bez obcinania,
- wyraźny autor każdej wiadomości,
- emoji picker,
- wybór zdjęć i plików,
- podgląd zdjęć w wiadomościach demonstracyjnych,
- działający przycisk „+” do nowej rozmowy (demo),
- działające menu „⋮” w rozmowie (demo),
- większe i czytelniejsze pola oraz przyciski,
- tryb demonstracyjny — brak połączenia z serwerem.

## Ważne
To nadal NIE jest prawdziwa komunikacja sieciowa ani prawdziwe E2EE. Szyfrowanie end-to-end zostanie wdrożone dopiero wraz z backendem i właściwym protokołem kryptograficznym.
